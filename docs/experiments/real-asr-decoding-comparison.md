# 固定模型：greedy 与 beam 解码对照

日期：2026-10-26。起始代码 `337bb89`。状态：十二场对照已完成，G/B 各 6/6 完整结束，CER=35%/42.5%；本轮不采用 beam/4，见[结果记录](../worklog/2026-10-26-real-asr-decoding-results.md)。下文保留运行前计划，未按结果调参或改判据。承接[同 PCM 直接探针对照](../worklog/2026-10-26-real-asr-direct-diagnostic.md)。

## 问题、原理与取舍

两段错误在绕过 Worker/Gateway 后完全复现。现在固定模型与输入，检查搜索策略是否影响重复字和数值错误。greedy 主要沿当前最有把握的一条候选路径继续；beam 保留有限条候选，再随解码推进比较，有可能减少过早选错造成的错误，但计算量可能增加，不保证一定改善。

本轮采用 SDK 已明确支持的 `modified_beam_search`，路径预算固定为 4。4 是一个小规模诊断预算，不是已调出的最佳参数；本轮不搜索更多路径数。备选是直接换模型、添加热词、改输入特征或输出去重；这些会改变其他条件，暂不混入本轮。尤其去重可能损伤合理重复和自我纠正，也无法纠正温度数值。

探针中增加解码参数，生产 Worker 保持既有行为。这样可以在选配置之前保留业务基线；代价是探针结果不能自动证明完整 Gateway 路径已支持 beam。

## 固定输入与条件

- 使用首轮冻结的 q01～q06 WAV/PCM 与录制者确认参考，不重新录制或转换。六段合计 2651478B、82.8586875 秒、归一化参考 200 字；素材均已见过，不是留出验证。
- 同一个非 race 探针程序、同 SDK `sherpa-onnx-go-macos v1.13.8`、同四份 int8 模型及 revision，CPU 两线程、16kHz/单声道、100ms 块、300ms/600ms 首尾零 padding、无 endpoint/reset。
- G：`greedy_search`、MaxActivePaths=0；B：`modified_beam_search`、MaxActivePaths=4。greedy 下拒绝非零路径预算，beam 下必须显式提供合法预算；报告记录实际传给 SDK 的配置。
- 每个素材每种策略各一次，共十二个独立探针进程。固定顺序：G_q01→B_q01、B_q02→G_q02、G_q03→B_q03、B_q04→G_q04、G_q05→B_q05、B_q06→G_q06。顺序交替只减轻单向时间顺序影响，不构成统计重复。
- 每场进程保护 60 秒，期间持有唤醒保护；保留 stdout/stderr、退出/超时、逐调用事件和 summary。失败/未知不删除，不补场覆盖，不作为空转录计分。
- 输入、参考、模型、程序、代码与本计划在运行前记录摘要；不传探针 `-reference`，统一用质量工具现有的 NFC/字符规则计分，避免混用旧探针归一化。

## 验证与指标

先核对实际配置、SDK/模型/程序/WAV 摘要、输入块数/字节、padding、InputFinished、排空与 Close 返回，再计算最后全文的 S/D/I/N 和 CER。每组固定六个槽位，汇总采用总错误数/总参考字符数；若某场未知，注明成功子集覆盖，不能把两个不同子集的总 CER 写成等素材收益。

本轮 G 也重新运行，不直接用上轮耗时作对照。G 的文本与既有六段基线逐段核对；若新增参数改变默认文本，先保留现象并定位，不把它算成 beam 收益。若两组完整同素材可比，报告逐段和合计 CER 差值，以及 q05 数值和 q06 自我纠正原文；相同的素材不增加独立语料数量。

计算代价记录 EngineCallNS 及 call_rtf：前者为探针已有 Accept/Decode/GetResult/InputFinished 包围段总量，含 padding，排除模型加载、人为排期、Ready、输出与释放；不是端到端 CPU 总成本或并发容量。两组相同口径可作本轮描述，但每格只有一次，不宣称稳定加速比或最优路径预算。最大计划落后、首字与尾部计时另列，未预登记时间合格阈值，不作实时性达标判定。

工具在正式运行前通过参数映射/非法输入与原探针回归。运行后复核数据不合条件时保留失败；原始文本不纠错、不去重复字。事实对照注明助手初评，人工审核状态继续保留。

## 后续决策

本轮不提前决定启用 beam。若字符错误减少但关键事实仍错，分别陈述；若整体改善且代价可接受，再验证 Gateway 组装及未参与选择的新素材。若改善有限或关键错误仍明显，优先考虑同素材后端对照。无论结果如何，六段首轮 35% 基线保持原样。

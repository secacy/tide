# 两个中文流式模型及配套特征：六段配对实验

日期：2026-10-26。以下为执行前冻结计划；同日[十二场结果](../worklog/2026-10-26-real-asr-model-results.md)已保存，原判据保留。依据[模型对照设计](../worklog/2026-10-26-real-asr-model-comparison-design.md)及[技术冒烟](../worklog/2026-10-26-real-asr-model-smoke.md)，只开展本机离线比较。

## 为什么测，以及方案取舍

当前旧模型 greedy 在六段录音上 CER=35%，beam/4=42.5%，体温仍错。候选已能流式出字并正常收尾，本轮用同素材验证换模型是否有实际收益。相比直接修改生产 Worker，独立探针能先隔离识别行为；代价是本轮不能证明 Gateway 完整链路的性能或结果一致性。

候选 encoder 声明 Whisper 特征，SDK 会自动采用配套特征处理，所以比较对象是模型与原生配套配置组合。共享 SDK 也不能排除运行时的共性问题。保留原始文字，不通过重复字删除或临床文本纠错提高分数。

公开原始模型页面仍要求登录并接受访问条件，导出 README 和维护者说明未补充权重许可声明。本轮没有得到权重使用条件的确认，亦不将第三方标注或源码许可证视作权重授权。[原始页面](https://huggingface.co/yuekai/icefall-asr-multi-zh-hans-zipformer-large)、[维护者固定说明](https://huggingface.co/csukuangfj/icefall-asr-multi-zh-hans-zipformer-large/blob/d17b865e7988f9e2f67d2b8bb4af24aa3be09f48/README.md)

## 固定条件与十二槽位

| 条件 | A | B |
| --- | --- | --- |
| 模型 profile | zipformer-bilingual-2023 | zipformer-zh-2025 |
| 资源 | 原 bilingual int8，四组件固定摘要 | 已冒烟的中文 2025 包，四组件固定摘要；decoder.onnx |
| 配套特征 | 旧模型元数据，无 Whisper 标记 | 元数据 feature=whisper，由 SDK 自动选择 |
| SDK、执行环境 | 两组同一程序，macOS arm64，sherpa Go v1.13.8，CPU 两线程 | 同 A |
| 搜索与流式参数 | greedy/0，16kHz/80 维，100ms 送样，300ms/600ms padding，endpoint 关闭 | 同 A；内部模型步长可不同 |

固定 q01～q06 原 WAV/PCM/参考，每组各处理 2651478B、82.8586875 秒音频，200 个规范化参考字符；参考来自录制者先前确认。无需重新准备音频；核对原始 m4a、WAV、PCM、参考摘要。六段已多次使用，只是候选选择素材。

顺序固定 A1→B1、B2→A2、A3→B3、B4→A4、A5→B5、B6→A6。每格一次、独立进程；同一 v3 探针二进制、SDK/随包原生库和资源在执行前后校验摘要。参考不传给探针、不改增益、不重采样、不添加热词/标点/数值归一化/文本纠错。

每场 60 秒进程保护；开始前写全十二槽位，未执行为 unknown；非零退出或超时为 failed。成功空文本按全部删除计分；失败和未执行不等同成功空文本。若修工具须保留本轮并另建编号，不补场替换不利结果。

## 观测与判据

- 保存全文变化事件及最终快照、SDK 有效参数、输入偏移/块、Finish/Close 和进程退出。逐场重算后才能计入成功分母；两组均完整六段时计算合计 CER 差值。
- 延用现有 NFC/ASCII 小写/去指定句读评分，保留数字写法、小数点和全文内重复字符；保存 N/S/D/I、逐字对齐、加权合计。不同数值写法对 CER 的影响另解释，不为候选改规则。
- 比较输入期间出字段数、加载后首字等待、尾部刷新、最大排期落后、加载耗时及 EngineCallNS/call RTF。调用计时不是总 CPU；每格一次，不推算稳定性能或并发容量。峰值 RSS 本轮不采集，不补写资源收益。
- 维持 `caffeinate -i`，独立每 500ms 记录单调时间及 UTC，报告最大间隔和超过 3 秒的采样缺口；该阈值仅标记观测质量，不是业务延迟 SLA。出现缺口仍保留质量文字，时间结论单独限制。
- 将 A 最后全文与既有 Gateway greedy 逐字比较；任何变化先报告调查，不能把改造探针造成的差异当成模型收益。
- 既有 19 项事实由助手进行可回溯的文字初评，判断为保留/错误/无法确定，人工确认保持 pending；不自动用 CER 代替关键事实准确性。

进入新素材验证的建议条件沿用设计：B 六段完成且均输入期间出字，合计字符错误少于 A，助手初评未发现新增关键事实错误；有不确定项则明确待审。体温、否定或过敏仍错时如实记录，即便 CER 下降也不能称为医疗可用。若没有收益则结束本轮，不自动试其他尺寸/精度/搜索预算。

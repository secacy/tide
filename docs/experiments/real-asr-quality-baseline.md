# 真实 ASR 短音频质量基线

日期：2026-10-26。状态：准备中；开发者已选择自录模拟问诊，尚无音频、冻结参考、运行结果或质量结论。承接[第七阶段中途评审](../worklog/2026-10-26-stage-seven-review.md)。

## 目标

在当前固定 sherpa 模型与 Gateway/v2 路径下，回答两个问题：短音频最终转录错了哪些字；否定、时间、数值及自我纠正是否表达正确。本轮为六段人工构造的小样本诊断，不是临床准确率或模型排名。

## 录音准备

六段分开录，每段目标 8～25 秒，实际不得超过当前 Worker 的 30 秒输入上限。安静环境、正常语速、录音设备和距离尽量一致；不必刻意压缩停顿，也不用为了凑时长拖长发音。一个人即可完成，不做说话人评测。内容为虚构，不加入真实患者资料。

手机或电脑已有录音工具均可。保留原始文件，不用先安装转换软件；可提供原始 m4a/WAV 等，助手检查后生成 16kHz、单声道、PCM S16LE 输入，并分别记录源文件和实际送入模型的 PCM 摘要。原文件不覆盖，不把改后缀当作格式转换。文件可放在本地独立目录并告知路径，音频默认不随代码提交。

这些句子描述虚构病史，不是用药建议。实际录音若自然出现“嗯”、重复或口误，应按实际声音记入参考；整段重录时先完成素材选择再冻结，不能根据识别好坏挑录音。每段保留原始音频、实际时长和录制条件。六段一人朗读不能覆盖口音、噪声、重叠讲话或自然医患交流。

## 参考文本如何核对

先听录音、后看模型输出。参考记录实际说出的完整内容，不照抄提示稿，也不纠正说话者病史。例如 q06 的“三天，不对，是五天”须全部保留，不能只写成“五天”。听不清的部分应在运行前重录或标记待核，不能用模型结果补齐未知字。

每段提供一个同名 UTF-8 文本，例如 q01.txt。数字优先依实际读音写成汉字，英文缩写按实际内容保留；人工核对完成后记录审核人/时间、音频 SHA 和参考 SHA，再运行识别。若只有录制者本人审核，明确记为单人参考，不冒充独立双人标注。此处“独立”首先指不以模型输出作为参考来源。

如冻结后发现参考确有错误，保留原参考、原因及修订版本，并重算完整集合；不只改表现差的条目或静默覆盖旧结果。

## 固定执行方式

- 一个固定版本的模型、SDK、Worker 与 Gateway/v2 客户端；CPU 两线程，沿用当前前后 padding、单场准入和无 endpoint/reset 配置。
- 每段分别新建逻辑会话，按 3200B/100ms 实时排期发送，保留短末块；顺序 q01～q06，各运行一次。重复测量不增加独立语料数量。
- 沿用现有闭环的 MaxPendingAudioBytes=0、Resume=nil 与其他预算；输入源为文件，不能写成已验证麦克风实时采集。
- 复用已验证的音频读取、Gateway 透明转发观察和客户端结果记录；保存每段原始 partial/final、实际输入 SHA、completed、错误和模型配置。
- 完整结束且结果记录有效时，使用该会话最后 final 的完整文本评分；不拼接 partial、不用生成模型改写结果。失败、缺失结果或证据损坏单列，不能作为成功的空文本转录或从计划分母中删除。

输入尚未就绪，因此本页不是已冻结的正式实验清单。录音、参考、代码及归一化工具摘要齐备后才记录本轮冻结版本；运行中如改配置需另起一轮。

## 评分口径

**字符错误率 CER =（替换 S + 删除 D + 插入 I）/ 参考字符数 N。** 以 Unicode 字符而非 UTF-8 字节计数，使用字符序列编辑距离；同时保留逐段对齐方便检查。归一化统一做 NFC、英文字母小写、去空白和常用句读 `，,。！？!?、；;：“”"‘’`。小数点、正负号、百分号和斜线不删除；不做同音替换、繁简转换、医学词修正或数值语义改写。

该规则保守地把“三十七点八”和“37.8”视为不同字符形式。因此 CER 用于观察文本差异，数字含义是否保持还需人工复核；不能据此把正确的数字格式化一律解释为病史错误。评分工具实现时固定规则版本和编辑路径的平局选择，测试中文多字节、插入/删除/替换、标点与小数、空输出等边界。

逐段给出 N、S、D、I 和 CER；汇总使用 `sum(S+D+I)/sum(N)`，不直接平均六个百分比。空参考不计算 CER；静音不属于本轮六段参考语料。若存在未完整完成的会话，成功子集的 CER 必须注明覆盖 x/6，同时列失败/未知数量，不得写为全量质量。

**关键事实另做人工对照。** 在看模型输出前，根据实际录音冻结检查项：

- q01：前天晚上开始；早起明显；夜间会咳醒。
- q02：右膝；一星期；上楼加重；没有摔倒。
- q03：没有胸痛；没有呼吸困难；快走心慌。
- q04：阿莫西林后起疹；本次没有吃阿莫西林；没有吃其他抗生素。
- q05：早上三十七点八；昨天最高三十八点二；四十二岁，含各自单位和时间关系。
- q06：病程由三天改为五天；位置由左改为右；昨天无发烧且今天早上开始。

共 19 项是提示稿对应的拟定项目；实际口述变化时须在运行前同步修订并冻结。逐项记录“保持正确 / 错误或缺失 / 无法判断”与输出证据，数字写法不同但含义相同可记保持正确；整场失败的检查项记无法判断。报告 x/19 等实际冻结分母和各类数量，不把同一句中的相关项当作独立统计样本，不称为自动医疗语义评估。

## 本轮成果与后续决策

本轮不预设未经业务论证的“CER 小于某值就可上线”。完成标准是六个计划槽位均有明确结局、参考与配置可复核、成功结果可评分、全部关键错误原样列出。完成率与质量分开报告，错误多也属于有效发现。

结果填写结构：实际素材与条件 → 完整/失败/未知数量 → 逐段及合计 CER → 关键事实对照 → 最突出错误及下一步。当前以上数值均未测量。

若出现明显的否定、数值或核心词汇错误，先考虑同素材的后端或解码配置对照，并保留额外未用于调参的样本；若继续当前模型，则把这组素材作为长对话分段改造的短音频回归。后一项仍需新的长音频及切段边界样本，不能以六段短句代替长时验证。

工具、测试、运行和结果分析由助手完成；开发者本步只需录音并核对实际参考文本。没有音频时不伪造 CER，也不将提示稿或合成语音当作自录实测。

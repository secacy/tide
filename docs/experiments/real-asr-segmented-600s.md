# 真实 ASR 固定分段：十分钟延长观察

日期：2026-10-27。依据 `61c756d` 的[两分钟基线](../worklog/2026-10-27-segmented-120s-results.md)。状态：已完成一次正式观察，见[结果与限制](../worklog/2026-10-27-segmented-600s-results.md)。冻结源码中保留运行前版本，以下条件与判据未改。本轮验证同一会话跨二十个片段后的完整性、等待与资源趋势，不推断并发容量或生产可靠性。

## 固定条件与唯一负载扩展

- 复用两分钟实验的同一 Worker 二进制，SHA256 `a8a112f2d8d9f65ae0e1dc45dc9b3e6c615f41168a855211d84c532e7d8fba1b`。模型、SDK、两 CPU 线程、greedy、观察开关和 30 秒段长保持；只通过已有 CLI 将整场上限改为 19200000B。
- 正式输入从 120s 扩展为 **600s，19200000B，20 段**；继续循环相同原始 321700B 公开 PCM，取整场长度。前 120s 与上轮输入完全相同。准备时独立核对原素材与旧二进制摘要，并冻结实际新驱动、源码、输入、模型与动态库。
- 一个 Worker、一个 Gateway、一个客户端，总名额及本地名额各 1。客户端按原固定采集时间轴读取 3200B 块，无重连；Gateway 的缓冲预算、发送/输出/收尾期限和 `MaxPendingAudioBytes=0` 均沿用[上轮条件](real-asr-segmented-120s.md)。模型处理进度仍未知。
- 顺序保持：约 10.053s 原素材预热 → 空闲 5s → 正式 600s → 空闲 10s → 同素材前三秒新场 → 空闲 5s。预热、正式、新场独立分母。正式 Run 预算由 150s 改为 630s（输入时长+30s），另两场仍为 150s；自然清理观察仍 5s，驱动总期限 12min。
- 不重启 Worker、不强制 GC、不自动补场；预计完整运行约 635s。失败立即落盘并停止，不替换失败槽位。使用 caffeinate 防止空闲休眠；采样同时检查单调与墙钟间隔，不能凭此排除所有系统干扰。
- 不改业务代码和识别策略。采集器只增加明确的 120/600s 档位及趋势汇总，原 120s 默认档保留；现有历史证据不改写。

## 判据与事先选定的趋势口径

完整性与清理沿用上轮：正式 19200000B 的传输 SHA 和二十段 float32 样本摘要一致，每段 480000 个原始样本；20 个唯一 final、连续 Seq、快照替换、RPC EOF、completed/ACK 一致；同场一次分配/RPC/模型创建和实际关闭、20 次成功流创建/同步释放，三场合计三个模型、22 个流；Gateway 自然归零、本地名额复用、后续新场完成。

仍按 500ms 采集 Worker RSS、驱动 heap/goroutine、Gateway 活动数和模型事件。正式场及两侧空闲必须覆盖；任一单调或墙钟采样间隔超过 3s，或 RSS 缺失，时间/资源质量标为不合格，完整性结果独立保留。预热后、正式后、新场后空闲 goroutine 分开报告。

正式期预先划为 **五个两分钟窗口**：0–120、120–240、240–360、360–480、480–600s，起点为正式场首次源 Read。每窗口报告：

1. 对应四段的“最后源块交付→客户端收取 final”最小值、中位数、最大值；保留全部 20 点，避免只比较首尾两个值。
2. 对应采样的 Worker RSS 最小/最大/最后值，驱动 Go heap 和 goroutine 范围；同时保留全部原始样本。
3. 每次后续流创建和每段释放的调用耗时、全场采集/发送落后和 EOF 收尾时间。

不在运行后选性能阈值，也不按一次曲线拟合“泄漏速度”。若后段 RSS 或等待持续增加，先报告事实与窗口范围；接口释放配对不能单独解释原生 RSS。若没有持续增长，也仅描述本次十分钟，不能证明任意时长有界。

两分钟历史结果仅作背景参考：本轮保持相同 Worker，但运行时系统负载不同；新驱动的输入持有量从 3.84MB 增至 19.2MB，RPC/汇总历史快照也更多，因此不把两次 Go heap 差值称为业务内存退化。结果回调仍只保存当前段，所有工具额外引用按上轮限制说明。

## 工具验收与归档

普通 Go race/vet、Python 测试先通过；新版复核器必须仍能核对旧两分钟归档，且旧指标不变。正式使用独立冻结程序；运行后核对身份，再独立复核及对真实数据损坏副本检查。新增“误用两分钟长度”和“片段末尾样本错误”检查，防止只放宽总量而漏测后段。归档源码、原始日志、采样、输入、复核及首次失败；没有实测值前不填写成果。

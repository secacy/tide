# 共享 Gateway 群体恢复正式基线

日期：2026-10-11。关联 [EXP-006-02](../experiments/group-resume-baseline.md)、[工具设计与验收](2026-10-11-group-resume-design.md)。

## 本步目标与选择

工具已通过缩短场景和 race 验收，本步按预登记运行完整五组各三批，保留全部 120 场。直接引入 jitter 虽可能分散请求，却会同时改变等待与次数消耗，缺少当前方案的事实参照；本步保持算法和预算，先把入口竞争、次数耗尽和自然清理分别测清楚。没有修改业务代码，也没有根据第三轮失败追加“成功复测”。

## 执行与证据

实测提交 `6d23d40`；工作区仅有既存 .gitignore、.DS_Store 和 testdata 差异，304 个相关源码/条件/工具文件测量前后 SHA256 一致。用一次非 race 构建执行固定 A/B/C/D/E 顺序，Go 1.26.5、macOS 26.6.2、M2 Pro、12 CPU、32GiB、GOMAXPROCS=12，运行时间 14:26:48–14:28:44（UTC+8）。

CPU/内存及系统日志查询最初受沙箱读取限制，随后以只读方式取得硬件信息；不影响已完成运行。自有 caffeinate 采集结束前存活，系统日志该窗口没有 Sleep/Wake 转换，采样最大间隔为 18.383ms。工具/源码未改变，因此本步以真实正式运行、独立计算及归档读回验证为主，没有重复上一轮 Go/Python 全量回归。

## 结果和解释

| 组 | 三批完整完成 | 总完成 / 计划 | 恢复尝试 | handshake_limit |
| --- | --- | ---: | ---: | ---: |
| A 无故障 | 8 / 8 / 8 | 24/24 | 0 | 0 |
| B 八个握手名额 | 8 / 8 / 8 | 24/24 | 24 | 0 |
| C 两个握手名额 | 8 / 8 / 8 | 24/24 | 43 | 19 |
| D 占位 500ms | 8 / 8 / 6 | 22/24 | 105 | 83 |
| E 占位 2s | 0 / 0 / 0 | 0/24 | 120 | 120 |

94 场完整完成，每场 192000 字节逐字一致、61 条结果各应用一次且完成确认写出。所有场仍各一条原 RPC，没有串场或回退新建。26 场 recovery_exhausted 均保留五次尝试与最近原因 handshake_limit；每场只处理 60800 字节、应用 19 条结果，51200 字节已采集未处理、80000 字节未采集。15 批自然清理合格不等于业务完成率 100%。

B 的成功恢复 ready 中位数为 5.09ms，C 为 104.25ms；减少入口名额后仍全部完成，但恢复等待和请求数增加。D 的完整完成率 91.67%，完整场新采集音频结果从 T0 计 734.50–1539.45ms，最大相邻 partial 间隔 814.37–1629.76ms；这些值只来自 22 个完整场，失败不能被时延统计掩盖。

D 每批在释放前已拒绝 24 次请求，释放后又拒绝 2/3/6 次。第三批 ID 6 和 8 在入口已开放后的约 709ms 与 1512ms 仍被拒绝，1513.85/1513.92ms 次数耗尽。这两场失败是正式结果，未改为工具失败或删除。

E 每批八场的恢复请求都聚集在 T0 的 0/100/300/700/1500ms 附近；在 1513.11–1516.42ms 用完五次，入口直到 2000.66–2001.30ms 才释放。五秒窗口仍有时间，但次数已用完。失败 RPC 从客户端返回到实际退出还保留 8484.30–8489.60ms，与独立十秒服务端保留相符；这段等待有界，并非“客户端停止就立即释放”。

## 局限与下一步

11419 个资源样本观察到会话/注册/RPC 峰值各八、goroutine 峰值 144；最大采集落后 5.587ms。采样不是原子或严格上限，尤其 C 的握手峰值采样为零但实际拒绝 19 次，短暂握手被 10ms 采样漏过；不能据此判断 Gateway 没有入口竞争。逐场 remote_idle_after_return_ms 的结束点是整批空闲，不能当作该场自身的退出时刻；实际 RPC 时间另取 worker.exited_at。

本轮没有对照验证 jitter，也没有真实弱网、模型或长时会话证据。下一步先预登记尝试次数对照：保持窗口、退避和负载不变，只改变次数，评估完成、请求成本和等待；再将请求分散作为独立对照。预算增加和随机退避解决的问题不同，同时调整会无法解释收益来源。

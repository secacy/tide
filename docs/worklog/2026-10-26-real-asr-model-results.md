## 结论与决定

同一批六段自录模拟问诊、每组 200 个参考字符下，旧模型 A 的 CER 为 **35%（70/200）**，中文候选 B 为 **2%（4/200）**，下降 **33 个百分点**，字符错误减少 66 个。两组均 6/6 完整完成、6/6 输入期间出字。A 的六段最后全文均逐字匹配原 Gateway greedy 基线。

B 的插入错误从 63 减至 0，但仍把体温“三十七点八”识别成“六十七点八”；q02 的“最近没有摔倒”变成“最近没有攀”，新增一项无法确定的事实。**本轮保留候选继续调查，不判定其通过关键事实关卡，不替换生产 Worker。** 更低的 CER 没有解决医疗内容正确性，2% 也不能换写成“临床准确率 98%”。

下一步优先围绕体温和摔倒史核查原音及新素材；新素材应在录制、确认参考后固定配置测量。当前六段多次用于候选选择，不是独立验证集。后续还需 Worker/Gateway 一致性验证、长对话分段及真实负载实验。

## 条件、范围与实际执行

- A 为原 `zipformer-bilingual-2023` profile；B 为 `zipformer-zh-2025`，即 `sherpa-onnx-streaming-zipformer-zh-int8-2025-06-30`。同一个新构建非 race 探针、SDK `sherpa-onnx-go-macos v1.13.8`、macOS arm64、CPU 两线程、greedy/0。
- 每组处理同样 **2651478B、82.8586875 秒**原始 PCM。原 m4a、WAV、PCM、参考分别核对摘要；未改音量、重录、重采样、热词或文本纠错。参考没有传给探针。
- 原排期每 100ms 送样，300ms/600ms 首尾 padding、endpoint 关闭。B 元数据使 SDK 自动采用 Whisper 特征，因此是模型与配套特征配置组合对照，不能将收益单独归因于权重、量化或某个架构组件。
- 按 A1→B1、B2→A2、A3→B3、B4→A4、A5→B5、B6→A6 执行，各独立进程、每格一次。十二槽位全部退出 0，无超时、失败、未知或补场。没有根据中途结果调整条件。
- 进程窗口 **2026-10-26 13:30:18–13:33:18（Asia/Taipei）**。持有 `caffeinate -i`，独立 500ms 时钟采样共 359 条，最大单调/墙钟采样间隔约 **509.09ms / 509.10ms**，未出现预登记的超过三秒采样缺口；这不等于完整系统睡眠审计。

权重使用条件仍未确认。运行前正式计划已将此前的本地实验前置条件修订为采用与分发前待办；本轮使用已有公开 release 权重作本机离线比较，没有访问受限 checkpoint、接受条款、分发权重或上传音频。实验结果不构成许可确认。公开来源与缺口见[资产冒烟记录](2026-10-26-real-asr-model-smoke.md)。

## 关键事实与选择边界

原有 19 项事实逐项列入归档 `assistant-fact-review.json`，保留两组全文、助手判断和待人工审核字段。它是基于已确认参考与输出的文字初评，本步没有独立回听，不当作人工或临床标注。

- q04 的阿莫西林后起疹、本次未服阿莫西林/其他抗生素，B 表达清楚；A 的起疹部分混乱，先前保守列无法确定。
- q05 的昨天最高 38.2℃、42 岁在 B 中表达清楚；**今早 37.8℃→67.8℃ 的错误两组均存在**，这是数值错误，不是中文数字与阿拉伯数字的格式差异。
- q06 的三天改五天、左改右和发热时间，在 B 中可读出；q03 两项否定也被保留。
- q02 的“最近没有攀”不能可靠证明“最近没有摔倒”。A 的“最近没有摔到”虽是同音字，但上下文仍较明确；B 在此新增疑点。它触发了计划中“存在新增关键事实不确定项则待审”的条件。

因此不能只因总错误减少就宣布候选验收通过。下一步的针对性核查用于解释问题及确定后续候选资格；即使之后继续测新素材，也不是默认生产采用。对于两模型共同的体温错误，当前证据不足以唯一归因于录音、前处理或模型，也不通过文字修正掩盖原输出。

B 的调用包围段总时间增加约 **58.5%**。计时包含 Accept/Decode/GetResult/InputFinished 和 padding，排除加载、Ready、排期等待、日志输出和释放；它不是完整 CPU 时间。独立进程也可能命中系统文件缓存，不把加载时间称为严格冷启动。

同条件下本轮观察到更少字符错误与更多调用耗时。两组均输入期间出字，但不能由单场 call RTF 或较小排期落后推算并发容量、稳定速度差或生产延迟改善。峰值 RSS 本轮未采集，没有资源收益结论。首字与尾部均沿用探针加载后时钟，不与 Gateway Run 起点指标混算。

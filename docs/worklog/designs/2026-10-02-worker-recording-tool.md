# Worker 采样文件与命令入口

日期：2026-10-02

状态：已实现并通过全项目 race 回归。此项由助手按调整后的分工完成，属于负载与指标采集工具；下一步接入 Gateway/Worker 联合观测实验。

相关：[Worker 处理观测设计](2026-10-01-worker-processing-observation.md)、[运行命令](../../command.md#worker-处理状态采样)。

## 解决什么问题

已有 HTTP 查询和周期采样能够读取 Worker 状态，但若只在内存中回调或打印，实验结束后无法可靠对齐负载窗口、核对缺失样本，也无法区分完整运行与中途退出。本次补齐独立进程和原始文件，让每次查询及最终退出事实可以复核。

## 方案与权衡

| 方案 | 优点 | 代价及选择 |
| --- | --- | --- |
| 直接复制 Gateway 文件层 | 修改范围容易理解 | 文件保护、取消收尾与错误保留规则会维护两份；本次不采用 |
| 公共配置、报告和命令全部泛型化 | 共用范围最大 | 暴露不必要的抽象，改变已有调用方式；本次不采用 |
| 私有文件层共享，公开类型与协议适配分开 | 保留 Gateway API 与文件格式，收尾逻辑只有一份 | 私有层需要泛型和回调；本次采用 |
| 接入集中指标系统 | 适合持续监控和多实例查询 | 当前先需要可归档、可复核的小规模实验原始数据；暂不引入 |

共享的是独占创建、计数、关闭和清单保存；Worker 状态校验及 JSONL 格式独立实现。Gateway 公开类型与 v1 字段保持不变；共用层错误增加 `snapshot` 上下文，底层错误链仍保留，不承诺历史完整错误字符串逐字兼容。命令层继续分别维护薄的参数/信号/退出适配，没有增加通用命令框架。

## 实现和数据约定

1. `WriteWorkerSampleJSON` 输出逐行 JSON。每条有 `source_kind=worker`、v1 版本、序号、UTC 查询起止时间、整数纳秒耗时、状态或错误。校验、编码成功后才写入，短写返回错误；失败查询仍是可以保存的样本。
2. `RunWorkerSamplingToFile` 独占创建样本文件，写成功才增加计数，停止后关闭文件。`RunWorkerRecording` 独占创建新目录并预留清单，采样结束后保存配置、计数和原始错误；启动后的取消也会保存。已有目录不覆盖、不删除，失败产物保留。
3. Worker 清单同样带 `source_kind=worker`，`output_path` 使用相对文件名 `samples.jsonl`。文件层与清单编码分别共用私有实现；公开报告保留具体类型。
4. `cmd/worker-sampler` 提供地址、间隔、单次请求期限、总预算与输出目录参数，拥有私有 HTTP 连接池，结束时回收。按期完成、至少一个查询成功且文件保存成功退出 0；提前停止、全失败或保存失败退出 1。信号由命令入口处理。

必须区分三个事实：限制已启用时计数可读；未启用时查询成功但 `processing=null`；查询失败时整个 `state=null`。后两种都不能填成零占用。成功计数和命令退出 0 只说明查询/记录条件满足，不保证容量观测有效、时间覆盖充分或所有查询都成功。

预算到期在核心层仍为 `context.DeadlineExceeded`，清单如实保留；命令通过自有预算原因判定是否按期完成。文件关闭不等于 fsync，文件也没有跨文件原子发布保证；强杀可能留下不完整产物。

## 验证依据

执行：

```bash
go test -race ./... -count=1 -timeout=150s -json
```

全项目 **1295 项叶子检查通过，12 个显式实验按默认设置跳过**，无失败或数据竞争报告。相关包为 loadgen 539 项、Gateway sampler 95 项、Worker sampler 96 项、Worker 命令 85 项。检查数用于说明正确性覆盖，不是性能成果。

- Worker 编码覆盖已启用、未启用、失败、无效计数、纳秒/UTC、转义和短写；清单覆盖停止分类、计数边界和错误保留。
- 文件编排覆盖取消后保存、旧文件/目录保护、同目录竞争和可移动目录；共用样本文件核心继续由既有 Gateway 文件层用例验证，Gateway v1 格式回归通过。
- Worker 命令覆盖真实 HTTP 的正常、未启用、混合失败、超时恢复，以及真实进程的预算结束、全失败和 SIGINT/SIGTERM 退出与文件保留。
- 新增真实 Worker → HTTP → 采样命令 → 文件的接线测试：先确认空闲样本，再通过 gRPC 发送两块音频，验证完整结果，并从保存文件依次观察到空闲、占用、再次空闲；逐行数量与最终清单一致。该短窗口是正确性检查，不是正式负载实验。

纯 writer 故障覆盖不等于真实磁盘故障注入，本轮未新增磁盘故障实验。未重跑历史正式负载基线，也未得出稳定容量或采集开销结论。

# 第五阶段：独立平滑加权轮询

状态：核心选择器由开发者实现，助手完成审查和测试；本步验收通过，Gateway 接入尚未开始。

## 问题与选择

[EXP-005-11](../../experiments/heterogeneous-workers.md)在两个单名额 Worker、逐块耗时 10ms / 20ms 下观察到：10 并发三批均未达标，慢实例几乎每次采样繁忙且存在等待，快实例仍频繁空闲。下一假设是按已知处理能力调整新会话分配比例，并通过同条件实验验证，而非预先宣称改善。

普通轮询不考虑能力差异。最少活跃会话需要登记和归还，而且相同会话数并不代表快慢实例压力相同。实时负载调度需要处理探测滞后、失败与分配振荡。本阶段先选静态权重，以较小改动检验分配比例的作用；它不适应运行中能力变化，也不保证任意时刻活跃会话比例。

算法选择平滑加权轮询，避免按权重展开列表。每次给全部实例的 current 加上各自 weight，按配置顺序选最大者，再扣除总权重。2:1 时序列为 A/B/A；同分使用严格大于比较保留先出现者。current 是选择分数，可为负，不是正在处理的会话数。

## 已实现契约

- WeightedWorker 将原 Worker 与固定正权重关联；ID 原值保留，列表内不得重复，Client 不得为 nil。
- 构造器拒绝空列表、空白 ID、非法客户端、非正权重和总权重超过 1000000；先检查剩余空间再累加。上限是配置和算术保护，不是容量限制。
- 构造时复制配置到私有 entries，各实例 current 从零开始。Client 引用仍由外部管理。
- 一把互斥锁保护整次加分、比较、扣分；选择期间不执行 RPC。每次选择 O(N)，N 为 Worker 数量，状态空间 O(N)。
- 每次 Pick 消耗一次选择；建流失败不回退。不探测健康，不调整权重，不迁移会话。
- 选择器须经构造器创建，使用后不得复制；零值和 nil 接收者不属于可用实例契约。

本次未发现需要修改的核心实现问题。保留既有 RoundRobin，为后续对照提供独立策略。

## 正确性验收

测试文件：[weighted_round_robin_test.go](../../../internal/workerpool/weighted_round_robin_test.go)。[运行记录与源码哈希](../../experiments/results/weighted-round-robin-validation-2026-10-03.log)。

运行 `go test -race -json ./internal/workerpool`，新增 32 项、包内共 47 项检查通过（统计包含父测试和子测试），无失败或跳过。

覆盖：非法配置和极值溢出输入；手工顺序 2:1、1:2、5:1:1；等权时与普通轮询一致；权重同比放大后顺序一致；输入、返回值和选择器实例隔离；保留 ID 及共享客户端身份；极端合法 999999:1 完整周期仍选到小权重实例。

并发测试使用 32 个调用方、各 700 次 Pick，总计 22400 次；5:1:1 配置的计数为 16000/3200/3200，后续周期顺序正确。此测试验证比例及竞态，不衡量吞吐、锁公平性或用户会话完成率。

仅新增独立选择器及测试，尚未改变 Gateway 调用路径，本步运行 workerpool 定向 race 验收；接入后再验证 Gateway 路由与生命周期行为。
